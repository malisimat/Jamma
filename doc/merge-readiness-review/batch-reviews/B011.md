## Characterization audit

The characterization sequence is truthful. At `897f33e`, production still normalized every persisted signed fraction into `[0,1)`. Parsing `-0.25` therefore yielded `+0.75`; with `M=1000` and each entity starting at 100, that old target happened to alias to 850 for the `M` loop but incorrectly produced 850 rather than 1850 and 2850 for `2M` and `3M`, 73 rather than 627 for length 777, MIDI position 850 rather than 2350, and automation-anchor correction `-750` rather than `+250`. The scalar preservation and signed endpoint test also rejected the old normalization. Canonical correction `44504cb` accurately records the result as 0 passed and 3 failed, rather than describing these red tests as passing prerequisites.

## Production and behavior assessment

No blocker was found.

- JamFile initializes a missing `transportoffsetloopfrac` to zero. For present well-formed numeric state, read and write retain finite signed values and clamp only outside the approved `[-1,1]` boundary; invalid/non-finite state safely falls back to zero. No file-version marker or downgrade guard was added, preserving the explicit F-045 policy.
- Scene's control range and setter now accept the same signed interval. The setter forwards the signed value to Station state and publishes the absolute fraction to the existing audio mailbox; it does not normalize negative input to a positive master-wrapped phase.
- Station retains the signed fraction for recording-start and newly-created-take state. Existing AudioHost code consumes the same mailbox value and calculates `round(fraction * masterLength)` once at the audio boundary. The B011 implementation neither duplicates that calculation nor moves it into each entity.
- The existing B010 `LoopTake::_ShiftDirectPlaybackCursors` path applies the resulting signed delta to every audio Loop through its own `ShiftPlayIndex` modulo and independently to the MIDI cursor through `_midiVisualLoopLength`. The same signed translation is passed to the MIDI automation correction, retaining its inverse-anchor sign.
- P11 covers `M`, `2M`, `3M`, non-divisor 777, and an independent 2500-sample MIDI loop from one signed `M`-derived target. The scalar test covers `-2`, `-1`, `-0.25`, zero, `+0.25`, `+1`, and `+2`, current writer/current reader round trips, clamped endpoints, and missing-zero default.

Static diff review finds no B011 production hunk in `AudioHost`, `LoopTake`, NINJAM desired state, sync-map, generation, invalidation, or `NoSync` code.
