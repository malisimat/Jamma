# Audio spectral surface contract

Status: implemented and covered by native spectral/controller/publication tests. Live GPU/input/listening verification remains pending; persistence is deferred. See [current validation and handover](audio-spectral-editor-handover.md). Older validation-history paragraphs below describe the preceding session.

Only one spectral editor is operational at a time. AudioSpectralEditor prepares one immutable CPU topology during scene construction (default 4095 time by 256 frequency segments, capped by AudioSpectralConfig). UV and index arrays are pre-sized and filled with the original coordinate expressions and triangle order. Fresh models retain the topology without copying its arrays. The editor retains approximately 32 MiB of CPU topology across closes, and uploads approximately 32 MiB of static vertex/index buffers once during startup resource loading with the window GL context current. Each model owns its own VAO, R32F height texture and display/editing state. An immutable buffer generation remains alive until its last model releases it; force editor resource reinitialization releases the active model's VAO before replacing the generation. A cache rejects preparation under a second live GL context until explicitly released. Scene resource teardown releases models and buffers before window context destruction. Deletion requires the owning context to be current; a lost or unrelated context never receives stale object IDs, and original context teardown reclaims abandoned objects. Custom test dimensions remain supported, without a global cache or a mesh warmup worker/readiness wait.

The R32F texture holds compressed magnitudes at grid vertices. Trusted incremental updates upload separate damage rectangles against the exact uploaded baseline; unknown baselines use complete uploads; vertex/index buffers do not change with edits. Texture capacity, vertex texture support, shader/palette availability and GL upload/draw failures report useful unavailable reasons and retain the waveform fallback. Startup static-upload failure permits retry through the model's existing initialization failure path. Height allocation, dynamic uploads, draw mode, shaders and picking remain unchanged.

Initialization validation on 2026-10-14: incremental x64 Debug and Release native-test and Jamma app builds passed without warnings/errors. All 79 spectral/snapshot tests passed in both configurations, including four unskipped hidden-window WGL integration tests. Tests compare complete original/new UV and index arrays at production and custom dimensions, bounds and diagonals; retained topology across fresh models/loops; isolated display acceptance; shared buffer readback and last-reference cleanup; missing context/upload failure retry; foreign-context rejection; independent model VAOs and model/owner force resets. Independent review found no remaining actionable issues under the single-editor lifecycle. Protected draw, display projection/upload, picking, navigation, stroke, DSP and callback methods are unchanged.

Five isolated serial runs per configuration on an Intel Core i7-6700K at 4.00 GHz, MSVC v145, measured these medians (milliseconds, no timing pass/fail thresholds):

| CPU operation | Debug | Release |
| --- | ---: | ---: |
| Original UV/index allocation and construction | 598.305 | 14.365 |
| Pre-sized UV/index allocation and construction, once at scene startup | 37.851 | 9.417 |
| First model construction using retained topology | 0.172 | 0.0177 |
| Repeated model construction using retained topology | 0.0430 | 0.0009 |

The CPU comparison includes array allocation/fill and excludes comparison/destruction. Model construction excludes GL, source preparation, FFT and full editor-open latency. A separate hidden WGL harness on NVIDIA GeForce GTX 960, driver 560.94, OpenGL 4.6 measured the original production-sized static buffer uploads: first submission 7.24 ms Debug / 7.55 ms Release, through forced `glFinish` completion 22.21 / 24.62 ms. Subsequent five-run medians were 6.28 / 6.51 ms submission and 18.19 / 20.24 ms completion. This supports retaining static GPU buffers; the forced fence is a measurement tool, not production code or a measurement of full window/frame latency. Static preparation now occurs at startup and is retained across opens. Height allocation/upload and first draw can still contribute to a pause. Interactive first-open/reopen/resize painting/navigation and listening smoke tests remain unverified. Session persistence still exports original PCM and remains deferred under the playback contract.

Display jobs resample requested magnitudes from the retained original analysis, independent spectral gain field and broadband envelope. This is the specified framewise modulation preview, rather than a new STFT of composed output. Compression uses a fixed reference/floor/ceiling. Each corner magnitude includes spectral and envelope gain before compression; bilinear interpolation then operates on normalized dB heights, avoiding exponential dominance by rising loud corners. The canonical heightfield always spans the full source time and frequency range, including DC. Viewports scale and clip it during rendering; matching CPU picking uses the same affine mapping and clipped bounds. Pan/zoom never resamples heights or queues work. Physical source Nyquist remains the canonical maximum. Time endpoints duplicate the wrapped first column. The explicit colour ramp runs black at exact silence, then dark blue, green, yellow, orange and red. Colours use full emissive brightness above a short lowest-level dark-blue fade, instead of being multiplied by height. Colour spans -90 to 0 dB separately from the unchanged -90 to +24 dB height range. Exact zero has zero height and black colour; there are no pitch/time guides or ambient/hover lifts. A cyan core/trail follows the Loop body phase.

The local rectangle has X endpoints ±R, depth endpoints ±0.78R (low frequency toward +Z), and height 3 to 3+0.25R. It reuses MIDI framing and the existing camera/orbit lifecycle. Mesh vertices morph from an annulus R±5%; the phase rotation matches the old waveform and disappears at the rectangle. The old waveform crossfades with restored GL depth-mask state, and the spectral view bypasses waveform-only mixer/Y scaling. Source preparation completes before the spectral reveal begins. The model and last display survive the reverse close animation and detach at target reset.

Display/picking coherence is explicit: texelFetch supplies exact vertex heights; each cell uses triangles (00,10,01) and (10,11,01). DisplayedSurface retains the successfully drawn immutable heightfield, radius, morph, play fraction and the exact folded clip-from-local matrix from the successful draw. Picking uses this value rather than pending data or the old flat picker mesh, and painting must remain disabled during morph/source acquisition.

Presentation CPU work stays on the dedicated spectral worker; UI/render owns GL upload. The independent visual lane alternates bounded editing and presentation work while the audio lane reconstructs playback independently. New requests do not repeatedly cancel useful running synthesis. Normal close/source invalidation cancels without joining. Persistent CPU and GL failure feedback is retained per request rather than presenting a permanent preparing message.

AudioSpectralPicking is implemented in isolation: local-ray slab clipping and bounded grid traversal intersect the exact displayed triangles, including flat silence, vertical/grazing rays and grid boundaries. LoopGridProjection now supplies shared local rays for existing planar MIDI projection and raised audio picking. Native numerical validation covers raised/flat intersections and retained transforms under translated, scaled and moved views. Live input/listening verification remains pending. A held ordinary brush retains its source anchor until the pointer moves, while movement repicks the displayed triangles. Parent layout animation does not cancel strokes; actual camera, viewport, source and readiness changes still do. Brush uniforms are explicitly registered and shader outlines use pixel derivatives.

The fixed grid count is independent of source duration and sample rate. CPU LocalVertex/picking and the vertex shader share HeightRadiusScale (0.25). Fragment derivatives of the interpolated local surface position provide a restrained fixed-light specular cue before brush/playhead overlays; silence stays black. Live GPU appearance still requires visual acceptance.

Display preparation caches logarithmic row-bin mappings and unclamped per-corner dB for identical frame pairs, reusing the previous next-frame pair when it becomes the first pair. Changing envelope gain adds one per-column dB offset; every corner is compressed and clamped before interpolation. Scratch is bounded to frequencySegments+1 worker-local records, freed on completion/cancellation, and stays within the existing display allowance. Coincident dense/sparse vertices retain identical height-domain interpolation.

Wheel controls resize physical brush support: plain wheel adjusts time/octave radii together; Alt-wheel adjusts the broadband time band; Shift-wheel zooms frequency and Alt-Shift-wheel zooms time at the pointer. Ctrl has priority and remains reserved. Shift-right drag zooms time horizontally and frequency vertically at captured click fractions; Shift-left pans both axes on the captured click-height plane without changing spans. Alt-left remains broadband editing; unshifted right remains attenuation. Radius controls remain bounded to 5 ms to 2 s and 1/16 to 4 octaves; each view span is at least 1/16 of its full source axis.

Alt-left horizontal movement changes the band centre while current logical Y controls its relative level. Time projection uses the frozen click-height plane and initial screen Y, subtracts the initially projected coordinate, then adds actual clicked source time and clamps to the loop extent. Pure vertical movement therefore has exactly the prior fixed-band effect despite perspective, projection rounding or changing mesh heights. Boost then move horizontally paints a constant relative plateau; a diagonal sweep follows interpolated logical Y. The footprint follows the current centre. DPI scale is captured once; horizontal projection remains in physical screen pixels while amplitude uses double logical pixels.

Viewport controls are UI-owned and copied with the model's last successfully drawn Surface under its existing mutex. The fragment shader clips using the exact EditorMorph uniform rather than interpolated morph values. Picking only sees the last successful texture and its captured viewport/matrix. Captured editing cancels on a changed displayed viewport/camera/radius; navigation permits intentional viewport changes but cancels on camera/radius/size/source loss. Close cancels display jobs off audio.

The lowest palette fade spans only 0.03 normalized colour height (2.7 dB); true zero remains black. The UI outline uses lattice-aware physical brush support. The 4096 by 257 height texture fits a 4096 maximum texture width. Host geometry is about 32 MiB; up to seven distinct 4.016 MiB heightfields plus row caches fit the unchanged 64 MiB host allowance. GPU resources are separate: about 32 MiB vertex/index storage plus 4.016 MiB texture. Display compression caches uncompressed per-corner dB independently of changing envelopes, adds one per-column envelope dB, clamps every corner before height interpolation, and reuses a previous next-frame pair when it becomes the first pair.
