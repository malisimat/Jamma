Rubber Duck Review

Why this should help: mouse movement no longer forces both a full picker redraw and synchronous GPU readback every frame. Async PBO readback decouples CPU from GPU completion, and picker work is skipped on frames that cannot change hover.

Risk tradeoff accepted: hover id can be one frame old on async path. Forced-pick interaction boundaries (resize/mouse down/up) use sync fallback when the async value is not ready yet.

Locking tradeoff accepted: non-blocking commit can defer scene commit by a frame under contention, but preserves render cadence.

Separation/encapsulation check: picker implementation details remain local to GlDrawContext and window gating logic remains in Window. No audio snapshot path changes were made.
