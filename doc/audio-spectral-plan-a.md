# Spectral responsiveness and recovery: plan A

## Findings and intended behavior

Dedicated agents investigated each of the five requested items. Drawing now rebuilds a 4096 by 257 heightfield on the same serial worker that performs whole-loop reconstruction. Recorded Release display costs are 37/49/62 ms for 2/10/30-second loops, versus 16/28/41 ms for the former mesh. Every result also incurs full UI validation and render diff scans. Navigation cancels and rebuilds this matrix; it currently increases display sampling density, but not FFT resolution. Time navigation has never been implemented.

The user confirmed the recovery failure is Alt silence followed by ordinary painting. Spectral authored silence already lifts from the -90 dB floor at 60 dB/s; the independent zero broadband envelope masks that recovery. Restoring the entire broadband envelope beneath a narrow brush would also restore unpainted frequencies and is unacceptable.

Retain current mesh and FFT tuning. Make views renderer-only. Give authoritative editing and local display projection an independent fast lane, so an in-flight audio reconstruction cannot delay visual input. Preserve original complex coefficients, immutable edit snapshots, undo and the last successfully drawn picking mirror. Plan B explores two more ambitious alternative authoring/rendering designs.

## Phase 1: recoverable masked coefficients

Use the existing copy-on-write gain payload plus a per-coefficient ownership bit, stored in each 32 by 32 tile. Unowned coefficients use the current spectral layer followed by the broadband envelope. Owned coefficients replace that primary contribution and reconstruct after the envelope, using retained original phase. No second dense gain field and no recursively accumulating recovery layers are required.

When ordinary paint first touches a coefficient with positive exposure beneath any non-unity frame-centre envelope gain, capture its current composed magnitude at the wrapped frame centre into the same gain payload and mark ownership. Do not use a near-zero threshold that causes a representation discontinuity. Exact zero seeds the authoring floor; subsequent exposure adds height/dB at the existing rate. Zero exposure must not migrate ownership. A coefficient originally absent remains absent. Attenuation and later boosts update that same target. Unpainted coefficients keep their mask.

Worker reconstruction omits owned coefficients from the primary pass, applies the immutable envelope to primary PCM, then reconstructs owned contributions using reused FFT/WOLA scratch and adds them into the same processed output. Publish composed PCM with a null playback envelope. Reuse/publication must key on both spectral and envelope revisions; never apply a newer envelope to stale already-composed PCM. Preserve the existing cheap path when no recovery ownership exists.

Alt edits also update owned targets against the stroke's captured values, rather than putting another zero multiplier after them. The normal sample-domain envelope remains for unowned content. The numerical recovery rule is explicit: neutral factor returns the exact baseline, zero factor produces authored zero, amplification uses max(baseline dB, floor dB) plus 20*log10(factor), with bounded output. For normal envelope gains the floor is -90 dB; for owned targets it is the existing absolute spectral magnitude floor. Owned Alt amplification retains the broadband +24 dB absolute headroom; ordinary painting retains its 0 dB ceiling. Attenuation retains the existing relative rule and zero threshold. Evaluate shoulders with the cumulative winning influence/factor against captured before-values, never against a previous batch's result. Zero influence leaves values untouched. Neutral reversal remains exact, including ownership bits and handles where content matches.

Ownership migration is a representation change and cannot preserve sample-exact output at a varying envelope boundary. Recovered coefficients necessarily have STFT time support rather than sample-exact band boundaries. Explicitly measure and test transition leakage with a selected tone and an unrelated tone, a flat-zero interior, near-zero masks, and both band boundaries. Unpainted coefficient payloads and ownership must remain identical; do not claim untouched time-domain samples outside an FFT window remain exact. Full composed display remains the specified framewise preview, not a new analysis of audible output.

Charge ownership bits in tile/history reservations. A bitset adds 128 bytes per 1024-value tile (about 3%); the conservative six-revision 30-second estimate should remain below 512 MiB. Reuse the existing target sums/weights and output storage instead of adding full PCM handles. Verify the actual peak, not only a nominal field size.

Tests: Alt silence then narrow ordinary recovery, unrelated frequency retention, steadily increasing visible composed height, almost-zero masks, true original zero, repeated batches, subsequent Alt cut/restore, forward/reverse sweeps, undo/cancel/reopen, prefix/seam contributions, revision races and admission. Independent review and phase commit after native validation.

## Phase 2: instant two-axis navigation

Always build the full-source heightfield. Store separate normalized time and frequency bounds on the model's captured Surface. Vertex positions use affine source-to-view mapping; retain source UV for sampling, brush and playhead. Fragment clipping hides source regions outside the visible rectangle. CPU vertices mirror the affine transform; ray traversal slabs clip to the visible rectangle while source cell indexing uses transformed full-grid bounds. Return source UV from picking.

Alt-left remains swept band editing. Alt-right becomes mouse-centred two-axis zoom: horizontal movement zooms time, vertical movement zooms frequency. Keep Shift-right frequency pan/zoom for MIDI familiarity. Shift-wheel zooms frequency at the mouse; Alt+Shift-wheel zooms time. Plain/Alt wheel retain radius controls; Ctrl remains reserved with priority. Capture modes and anchors once, use logical pixels, bound spans, and preserve the source anchor except at unavoidable edge clamping.

Navigation changes only model/view uniforms. It queues no display, authoring or audio job and uploads no heights. Picking/capture uses the last successful draw's view, never pending controls. Broadband horizontal time projection includes the captured time span. Opening/closing morph behavior remains explicit, without clipping the ring.

Tests: both axes and diagonal zoom, mouse anchor/clamps/DPI/modifiers, partial-cell clipping and hidden peaks, zoomed picking/brush/playhead, band time projection, immutable texture identity, no queued jobs, and navigation while audio is blocked. Verify shader registration/deployment. Independent review and phase commit.

## Phase 3: fast authoritative visual lane and incremental projection

Separate serialized edit/presentation work from analysis/reconstruction. Existing UI input matrices remain bounded; the fast lane owns mutable stroke gains/envelopes and publishes immutable receipts. Audio receives coalesced immutable edits independently. Release/undo/cancel authoring cannot wait for audible convergence. Use distinct cancellation domains: aborting obsolete audio must not cancel already accepted authoring. Gate reconstructed output by its exact source/revision pair; a running old result cannot overwrite a newer publication. Close may drain a final accepted stroke asynchronously, but source replacement invalidates obsolete work. No UI or audio join is introduced.

Build a canonical full-source display once. Track changed coefficient tiles and envelope source-time spans during authoring; map these to conservative display rectangles with interpolation/context halos. Copy the roughly 4 MiB immutable previous height vector and recompute only affected vertices, using the same composed corner magnitudes, clamping and interpolation as full projection. Empty changes do no work; source/transform/full restore changes take the full path.

Carry dirty rectangles plus their baseline display revision. Render subuploads only when its uploaded baseline matches; skipped/coalesced revisions fall back to a complete upload. Keep exact successful CPU snapshot for picking. Internally constructed results validate once off UI; public/untrusted display entry points retain complete validation. Avoid a full 1M-vertex render diff scan. Tighten high-frequency candidate bounds only with exact conservative support and subdivision tests.

Review simultaneous fast/audio worker scratch and retained lifetimes against current reservations. No mutex/FFT/allocation/wait is introduced in audio callbacks. UI only mutates active input; worker reads frozen maps until terminal release/acquire; stale source/revision results are rejected. Teardown joins off audio, normal close does not join.

Tests: block reconstruction and prove authoring/display completes before release; incremental/full equality across ordinary/recovery/band edits and seams; skipped upload baselines; undo/cancel/source replacement with backlogs; upload failure invalidates picking; memory admission with concurrent jobs. Profile input, authoritative edit, full/local projection and publication separately at 2/10/30 seconds. CPU evidence is not a GPU or end-to-end latency guarantee. Build library/tests/app and audit hot paths. Independent review and phase commit.

## Review and execution record

Plan B was reviewed and clarified regarding GPU memory/phase ownership and refinement tolerances. Fresh implementation subagents own each phase sequentially to avoid shared-file collisions. Primary reviews each phase, resolves findings and commits the verified result. ### Phase 1 completed: recovery representation and exact synthesis pairs

Implemented tile-local ownership bits in the existing copy-on-write spectral gain payload (128 bytes per 1024-value tile). Positive exposure under any non-unity frame-centre envelope migrates the composed baseline and then adds the existing 60 dB/s. No exposure or absent original coefficients leave ownership unchanged. Ordinary brushes recover a narrow region after Alt silence without restoring unrelated frequencies. Owned Alt targets evaluate against captured before-values and cumulative winning factors, with exact neutral reversal; matching restored gain content reuses the original handle.

Synthesis reuses the existing FFT, output, WOLA sums and normalization. Primary coefficients reconstruct first and receive the immutable envelope; owned coefficients reconstruct afterward. Empty owned frames skip the second inverse FFT. Baked PCM carries immutable source/envelope provenance and both component revisions, and its playback envelope is null. Publication rejects a composed result unless its captured spectral/envelope pair still matches the committed edit. Comparison uses authored envelope provenance on both old and new snapshots, allowing Undo to return to the original fast path with unchanged envelope revision. Original paths without ownership still share envelope-only PCM cheaply.

Thread ownership: gain tiles and ownership bits are mutated only by the serialized edit worker; published COW copies are immutable. Composed PCM metadata is constructed and stamped by the synthesis worker before immutable publication. Existing receipt release/acquire and published snapshot protocols protect handoff/lifetime; no additional mutable shared state or callback allocation, lock or wait was introduced. Both sums/weights and existing output storage are reused, and tile/history reservations account for the bitmap through sizeof(Tile).

Validation: incremental Debug library/tests builds succeeded; all 61 spectral tests passed. The tests cover zero/near-zero/non-unity masks, zero-exposure ownership no-op, original silence, additive rates, coefficient selectivity, captured Alt reversal, controller Alt-to-ordinary recovery, null playback envelope, Undo/Redo/reopen, and stale pair rejection. Two-tone recovery measured selected amplitude 0.666822 and unrelated 6000 Hz amplitude 3.32e-7; samples outside the union of owned FFT window supports were exactly zero. All-owned WOLA round-trip covered prefix/body/seam contributors within 2e-6. The conservative 30-second 4096/1024 estimate is 510.378 MiB under the unchanged 512 MiB cap. Hot-path audit and diff whitespace checks passed; callback bodies remained unchanged.

Limitation: ownership conversion under a varying envelope has STFT boundary support rather than sample-exact isolation. Exact component-pair publication may postpone composed audible updates until painting pauses when authoring outpaces synthesis; phase 3 must preserve correctness while profiling that case. Manual listening and GPU/input checks remain outstanding. Release synthesis profiles now include sparse-owned and all-frame-owned diagnostics for final combined validation.

### Phase 3 implementation: independent authoring and incremental presentation

The worker now has two serialized lanes: source/analysis/audio content/reconstruction on its original lane, and authoritative paint/presentation on a separate visual lane. Queue state uses the existing non-audio mutex and shared condition variable; all submissions notify both predicates. The visual lane alternates pending paint and presentation. Running edits keep their frozen input until Run exits; only queued edits receive terminal cancellation callbacks. Teardown joins both lanes off audio, with constructor rollback joining the first thread if the second cannot start. Close/source cancellation remains asynchronous.

Authoring batches use a separate 60 Hz interval; audio requests remain coalesced at 30 Hz and stroke release always queues the final exact accepted pair. UI accepts the immutable receipt, schedules presentation and retires terminal display receipts before the next batch. A worker-only cache retains only immutable height data and identity/revision metadata, never old edits/gains/source reservations. Incremental requests name both baseline and exact destination revisions. Any missing/skipped baseline, Undo/cancel/direct restore or source replacement without exact damage provenance takes the full path.

Gain application reports actual changed coefficient bounds, including owned Alt changes and ordinary ownership migration. Envelope damage compares newly published sample values with the previous snapshot, so local ramps and seam changes are covered. Projection includes both adjacent interpolated frame/bin corners and the duplicated wrap endpoint. Incremental builds copy the roughly 4.016 MiB height vector and recompute only affected rectangles. Corner dB and ownership flags are cached together, with ownership lookups skipped entirely on ordinary unowned fields. The public builder validates arbitrary matrices and rectangle bounds; only the private cache path can bypass repeated million-value validation. Public display submission always forces complete GPU upload; completed worker jobs alone may authorize dirty uploads. Each dirty rectangle uploads separately (including the wrap endpoint), and a skipped uploaded baseline falls back to complete upload. Any failed upload invalidates the CPU picking mirror.

Ownership and lifetime proof: queue/current handles and stopping flags are owned by UI plus their designated worker under the request mutex; both worker threads join on owner teardown. Visual preference is used only by the visual lane under that mutex. Cache data is private to DisplayJob and read/written only by serialized visual jobs; jobs retain the cache on source teardown. Damage and requested cache handles are UI-owned immutable captures. Model pending trust metadata is written by UI under the surface mutex and copied by rendering with the pending height handle; no worker or audio callback reads it. Prepared display revision is UI-only and records accepted CPU presentation, not successful GPU draw. Change bounds are stack-local to the edit worker and copied into release/acquire receipts.

Conservative resource accounting is unchanged: six full gain generations, input scratch max(36*C,72*N), existing envelope scratch, and the 64 MiB display allowance. At candidate mutation, one visual operation runs; current edit and current display cannot overlap. The six distinct generations can be stroke before; mutable base sharing tiles with latest accepted/queued presentation edit; temporary transactional candidate; one terminal presentation old edit; running audio capture; and queued audio capture. Only one unaccepted paint receipt exists, preventing mutable/accepted divergence before another mutation. After candidate move/snapshot, receipt and mutable field share the newest tiles until the next fork. Input events can queue a batch before UI receipt pruning, so the terminal presentation slot remains explicitly charged. Cancellation can retain one old edit closure, but the next mutable candidate cannot allocate until that same serialized lane exits and releases the old closure. New UI before/latest handles alias accepted/queued display content. Undo history is independently charged and initial unity fields allocate no dense tiles. The 30-second baseline estimate remains 510.378 MiB within the 512 MiB cap.

Height lifetime includes model pending/uploaded/last-drawn (three conservative), canonical cache (one), just-completed UI receipt (one), and current builder baseline/result (two). These are often aliases; seven distinct 4.016 MiB matrices plus approximately 32.03 MiB static geometry remain below the 64 MiB CPU display allowance. UI drains all terminal receipts before queuing another presentation. Source replacement cancels prior jobs; cancelled builders cannot publish to their cache, and old worker closures release their private captures before another visual operation runs. GPU geometry/texture allocations remain separate from the CPU admission estimate.

Validation and measured timings are appended after final builds. Exact composed pair publication remains strict: visual input can continue independently while obsolete synthesis is rejected, so continuous painting may postpone audible convergence until input slows or stops. Native CPU profiles do not establish GPU draw timing or end-to-end input latency.
