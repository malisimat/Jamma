# Audio spectral surface contract

Status: implemented and covered by native spectral/controller/publication tests. Live GPU/input/listening verification remains pending; persistence is deferred. See [current validation and handover](audio-spectral-editor-handover.md). Older validation-history paragraphs below describe the preceding session.

AudioSpectralModel builds a single indexed grid per opening/configuration (prototype default 512 time by 128 frequency segments, capped by AudioSpectralConfig). An R32F texture holds compressed magnitudes at grid vertices. Updates replace only a changed bounding rectangle; vertex/index buffers do not change with edits. Texture capacity, vertex texture support, shader/palette availability and GL upload/draw failures report useful unavailable reasons and retain the waveform fallback. GL resources use GlDeleteQueue.

Display jobs resample requested magnitudes from the retained original analysis, independent spectral gain field and broadband envelope. This is the specified framewise modulation preview, rather than a new STFT of composed output. Compression uses a fixed reference/floor/ceiling. Each corner magnitude includes spectral and envelope gain before compression; bilinear interpolation then operates on normalized dB heights, avoiding exponential dominance by rising loud corners. The lower row explicitly handles DC; positive rows use logarithmic frequency through Nyquist. Time endpoints duplicate the wrapped first column. The explicit colour ramp runs black at exact silence, then dark blue, green, yellow, orange and red. Colours use full emissive brightness above a short lowest-level dark-blue fade, instead of being multiplied by height. Colour spans -90 to 0 dB separately from the unchanged -90 to +24 dB height range. Exact zero has zero height and black colour; there are no pitch/time guides or ambient/hover lifts. A cyan core/trail follows the Loop body phase.

The local rectangle has X endpoints ±R, depth endpoints ±0.78R (low frequency toward +Z), and height 3 to 3+0.5R. It reuses MIDI framing and the existing camera/orbit lifecycle. Mesh vertices morph from an annulus R±5%; the phase rotation matches the old waveform and disappears at the rectangle. The old waveform crossfades with restored GL depth-mask state, and the spectral view bypasses waveform-only mixer/Y scaling. Source preparation completes before the spectral reveal begins. The model and last display survive the reverse close animation and detach at target reset.

Display/picking coherence is explicit: texelFetch supplies exact vertex heights; each cell uses triangles (00,10,01) and (10,11,01). DisplayedSurface retains the successfully drawn immutable heightfield, radius, morph, play fraction and the exact folded clip-from-local matrix from the successful draw. Picking uses this value rather than pending data or the old flat picker mesh, and painting must remain disabled during morph/source acquisition.

Presentation CPU work stays on the dedicated spectral worker; UI/render owns GL upload. The worker has bounded latest pending presentation with explicit cancellation callbacks, and alternates presentation/reconstruction when both are ready. New requests do not repeatedly cancel useful running synthesis. Normal close/source invalidation cancels without joining. Persistent CPU and GL failure feedback is retained per request rather than presenting a permanent preparing message.

AudioSpectralPicking is implemented in isolation: local-ray slab clipping and bounded grid traversal intersect the exact displayed triangles, including flat silence, vertical/grazing rays and grid boundaries. LoopGridProjection now supplies shared local rays for existing planar MIDI projection and raised audio picking. Native numerical validation covers raised/flat intersections and retained transforms under translated, scaled and moved views. Live input/listening verification remains pending. A held ordinary brush retains its source anchor until the pointer moves, while movement repicks the displayed triangles. Parent layout animation does not cancel strokes; actual camera, viewport, source and readiness changes still do. Brush uniforms are explicitly registered and shader outlines use pixel derivatives.
