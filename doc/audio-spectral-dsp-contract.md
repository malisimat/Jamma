## Transform and coordinates

AudioSpectralConfig names v1 prototype defaults and limits. Transform version 1 prefers 4096-sample periodic Hann windows with 16-fold overlap (256-sample hop), with 512/1024-sample hop memory fallbacks, float real KissFFT, explicit 1/N inverse normalization, and samplewise weighted overlap-add normalization by the actual sum of window squared. Frame centres lie on a body-source hop lattice, extending beyond the prefix-fade/body target. Reconstruction clips each frame to its actual target coordinates, rather than wrapping every window contribution into a short loop. This avoids counting repeated wrapped samples as multiple output contributions.

Source body zero is storage offset MaxLoopFadeSamps. Analysis reads captured prefix and physical tail whenever available; only missing context extends the logical body periodically. Reconstruction replaces the prefix-fade region and logical body, preserving earlier prefix and unrelated physical tail exactly. See audio-spectral-source-contract.md for layout and the confirmed equal envelope gain on both existing seam contributors.

## Independent edit layers

AudioSpectralGainField stores finite relative dB values in copy-on-write 32 by 32 tiles, plus a distinct finite authored-silence tag. Ordinary painting now clamps absolute normalized one-sided magnitudes to 0 dB (red) and reaches exact zero at the -90 dB visual floor, following the user clarification on 2026-10-12. The former -60/+24 dB relative brush limits caused quiet bins to plateau below loud bins; they no longer constrain spectral painting. The bar retains its separate +24 dB gain bound. Double gain scaling covers very quiet nonzero originals without overflowing an intermediate float gain; reconstructed coefficients are checked finite before inverse FFT. Zero gain reconstructs authored silence exactly; positive scaling retains original phase, and immutable originals permit boosting back from authored silence. Originally zero coefficients remain zero. Unity reconstruction returns the original source handle without copying or transform arithmetic. The optional forced unity round trip exists for later native normalization validation. Edited inverse transforms preserve finite headroom without global peak normalization or a new limiter.

Ordinary brush centre exposure is 60 dB/second (2 dB per nominal 30 Hz publication), pending live listening calibration. The central 75% of the oval has full strength, with smooth squared shoulders. Effective time support is at least one hop and each bin has at least its neighbouring logarithmic bin spacing of support, so minimum brushes between coefficient centres react at the same centre rate. Ordinary brush exposure integrates this compact oval analytically along each straight pointer segment in source seconds and log-frequency. The UI rasterizes into preallocated exposure matrices, visiting only affected hop-lattice row ranges and bin ranges. Frozen batches are applied once per dirty cell on the worker; directional saturation is equivalent to sequential samples within one latched stroke. UI reads pending maps without mutating them until the worker terminal receipt, giving immediate authored-level feedback independently of synthesis. Physical seconds/octave radii are captured once per stroke and shared with its outline; display resolution never enters the DSP brush operation. Elapsed time scales exposure, independent of event count for the same piecewise linear time-parametrized path. Time support uses nearest wrapped distance; callers supply intended unwrapped movement. DC/sub-floor bins use the explicit lower frequency edge.

AudioSpectralEnvelope is a separate immutable dense linear-gain layer. Alt-left captures clicked source time, physical band radius, upward-positive double logical Y and before-envelope E0. Drag displacement chooses unity at the anchor, exact zero at -160 logical pixels and bounded +24 dB at +160 pixels. Vertical-only edits preserve the former rounded first-click sample by capturing one fixed sample-alignment offset. Horizontal movement sweeps relative factors across source time; diagonal segments interpolate logical displacement before nonlinear factor conversion, so subdividing the same path does not change it. Full-strength centre samples receive E0 times the factor; smooth compact shoulders multiply E0 and obey gain bounds. Prior zero samples remain zero through local ramps. Strongest spatial influence wins, with later equal influence winning by FIFO input/map application. Returning to neutral restores the currently visited band against E0 while distant swept changes remain. Stationary holds do not compound. Only the cumulative relative-map path is retained; obsolete absolute painting APIs were removed. Unowned coefficients receive the envelope after WOLA; recovered owned coefficients reconstruct separately into the composed output. Composed PCM carries the exact spectral/envelope revision pair and has no additional playback envelope.

Two preallocated relative winner maps preserve all path geometry while the worker is busy. Each uses 24 bytes per source sample: double influence/displacement and uint32 run IDs/dirty indices. UI accumulates one map and freezes the other into a receipt. The worker reads the frozen map without mutation; terminal release/acquire returns it before UI clears/reuses it. Cumulative worker scratch retains E0-relative winners across batches. Run IDs describe contiguous collinear same-direction paths solely for competing-winner ramp provenance; they do not determine temporal priority. A scale-aware double-epsilon cross-product check keeps subdivisions in one run; reversal, slope change or stationary Y adjustment begins another. Run tracking survives map clearing, and uint32 rollover reports/cancels instead of silently wrapping.

## Ownership and resource bounds

The dedicated worker prepares source storage and analyzes complete immutable sources. AudioSpectralAnalysisJob publishes its immutable result/reason through release/acquire terminal state; cancellation requests no worker wait. The worker has one running job and latest pending job, prioritizes pending source preparation, and destroys bulk payloads outside its queue mutex. Editor close cancels without joining; owner teardown joins off audio. No FFT, dense envelope construction, or reconstruction runs on callback or the input-pump job thread.

The editor preflights estimated memory before source storage preparation. The estimate reserves six full PCM handles, three retained analyses (previous visible, cancelled running, newest), fully materialized gain tiles with overhead, envelope stroke/retained storage, WOLA scratch, display and history budgets. Standalone gain fields also bound full possible tile storage. Limits are initial tuning values, not measured latency guarantees. Unsupported sources receive a useful reason.

The controller rejects analysis results from obsolete source identities/generations and retries after punch/record completion. Previous completed analysis may remain visible while reacquiring; readiness is required before dependent editing/publication. Capture and analysis never postpone punch-in.

New source admission tries 4096/256, then 4096/512 and 4096/1024 when the conservative per-source estimate or session reservation fails; all retain the 512 MiB cap. Higher-detail candidates leave 160 MiB headroom for another short loop; the final fallback can use the full cap so long loops retain admission. Existing edit states retain their exact stored transform. KissFFT plans and scratch remain reused per analysis/reconstruction job; no FFT work moves to audio callbacks.

Relative input scratch shares the source admission allowance with ordinary coefficient maps: max(36*C, 72*N), where C is coefficient count and N is logical samples. Three maps cover active/frozen and one running cancelled map. Mixed transitions fit too: 12*C+48*N and 24*C+24*N are each bounded by that maximum. The existing 64*N envelope/retained allowance covers worker winner/gain scratch and retained envelopes. Standard 4096/1024 and denser transforms keep their prior admission estimate; low-overlap stored transforms receive the larger sample-map allowance. Cancellation synchronously removes queued editing, drops active/spare UI maps immediately, and leaves at most the single worker's running frozen map pinned until terminal destruction.

| --- | --- | --- |
| BandInput/BandSpare, BandPath, BandDrag, SampleAlignment, double AnchorY | UI constructs and mutates; worker reads immutable stroke geometry only | Map ownership moves into receipt; UI drops scratch on finish/cancel. |

| EnvelopeStroke relative-mode flag and cumulative winners | Worker only | Never published mutable; released with worker stroke after receipt completion/cancellation. |
| Frozen band click seconds / screen anchor / DPI scale | UI only | Captured once; source/camera/size/readiness changes cancel pointer capture. |
